# Security policy

## Report a vulnerability privately

Use **Report a vulnerability** on the [Keynest Security Advisories page](https://github.com/JordyNicholas/Keynest/security/advisories). Use public issues for ordinary bugs. Keep suspected vulnerabilities and related details in the private report.

Include the affected version or commit, deployment configuration relevant to the issue, steps to reproduce with synthetic data, and the impact. Redact real passwords, session tokens, encryption keys, provider credentials, and vault data before submitting.

The maintainer will triage private reports and coordinate disclosure through the advisory. Include any disclosure timing constraints in the report.

For the public trust/custody overview, read the [security model](docs/security/overview.md). Deployment guidance and deeper limitations are in the [threat model](docs/security/threat-model.md) and [operations guide](docs/operators/runtime.md).

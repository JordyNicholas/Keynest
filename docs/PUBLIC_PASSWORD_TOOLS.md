# Public homepage password tools

The maintainer approved implementing and merging two homepage accordions, collapsed by default and positioned above “From generation to rotation”. At most one panel is mounted/open. Generate retains the fixed packaged default policy and local Web Crypto generator. Check reads a masked, bounded input locally and retains only derived rule flags; no sample, generation result or checker request is sent to the API or browser storage.

The checker reuses account-policy feedback helpers with the packaged default rules and the one supported blocked-pattern check. Unicode checks that cannot be confirmed locally remain explicitly unconfirmed. Results are policy feedback, not strength/security certification. Username matching/final Vault validation still happen in the authenticated save flow.

Closing, switching, Back to top, hiding or destroying the page clears generated/sample state immediately, before closing animation. Only the active component is mounted. “Try the generator” opens Generate and scrolls/focuses its header, including repeated clicks. Direct /#generator and /#check anchors work. Material headers supply keyboard behavior and follow the existing reduced-motion configuration. Public authentication stays in the shared header/dialog; no public tool route or standalone login form is introduced.

Automated coverage checks default/anchor/keyboard interaction, local policy feedback, no requests/storage and immediate cleanup. The human browser/responsive walkthrough remains open. Revert this UI slice to roll back; there is no database or session change.
